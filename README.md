# 🌦️ Weather App

A modern and responsive weather application built using React.js, Vite, and WeatherAPI. This app allows users to search any city and get real-time weather updates with a beautiful glassmorphism user interface.

## 🚀 Live Demo

https://weather-app-ten-rho-94.vercel.app/

## ✨ Features

* Real-time weather updates
* Search weather by city name
* Responsive design for mobile and desktop
* Beautiful glassmorphism UI
* Dynamic weather icons
* Error handling for invalid city names
* Secure API key management using `.env`

## 🛠️ Tech Stack

* React.js
* Vite
* CSS3
* WeatherAPI

## 🔧 Installation

```bash id="9jlwm7"
git clone https://github.com/nishika931/weather-app.git
cd weather-app
npm install
npm run dev
```

Create a `.env` file in the root directory
